# Workspace visual system

Reference: official shadcn/ui `dashboard-01` and `sidebar-07` blocks. This replaces the previous blue gradients, large navigation cards and pill-shaped surfaces.

Savia Licitaciones also offers runtime adaptations of the Create styles: Vega (classic), Nova (compact), Maia (soft and spacious), Lyra (sharp, monospaced controls) and Mira (dense). Styles change shared control density, spacing and radius while preserving independent color and display mode. Document canvases retain their own font and formatting.

- Neutral zinc palette by default. Settings offers neutral, blue, green, violet and rose accents, independently of light/dark/system mode. Both choices persist in the user's configuration and synchronize across the web workspace. Semantic status colors remain reserved for actual state.
- Sidebar: 256px expanded, icon rail when collapsed, grouped navigation and directly accessible submenus. Mobile uses a dismissible sheet. Collapse is transient UI state, without browser persistence.
- Main workspace: inset panel, subtle border, 12px outside radius; compact 56px header with sidebar trigger, breadcrumb, language and theme controls.
- Typography: existing system font; 13–14px controls, 12px group labels, 24px page titles; regular and medium weights predominate.
- Surfaces: flat cards, 1px borders, restrained shadows; 24px desktop content padding and 16px small-window padding. Tables and forms follow the same spacing and contrast.
- Preserve tool-specific layouts and document canvases. Exported pages remain paper-colored in dark mode.
- No placeholder analytics or fabricated dashboard data. Landing cards launch real existing workflows.

Internal screens use the same visual language: flat command headers, compact tabs, bordered lists and neutral selected rows. Status colors indicate actual results, not decoration. Workflow actions sit in a full-width footer outside the scrolling content; document review, feasibility and bid-generation flows share that treatment. Upload panels avoid nested cards. Pseudo-element hints are localized with the document language.

Color/background pairs must be reviewed together, including child labels on selected rows and file/error indicators. Document typography, canvas dimensions and preview corner tokens remain independent from the selected app style.

Opportunity search uses searchable category popovers for departments, procurement methods and status. Multiple selections appear as removable labels; categories come from the selected public dataset and load only when a filter is opened. The Savia app mark is an ivory leaf with a green S on a forest-green field; `client/assets/savia.svg` is its editable source, with platform assets generated by `client/scripts/build-app-icons.cjs`.

Verification: real web viewport screenshots at desktop and small widths in both themes, sidebar collapse/mobile navigation, full route/workflow matrix, and independent review before final integration.

Opportunity results use compact rows, sticky sortable headers and a bounded internal scroll area. Sorting and column filters query the selected source; infinite loading retains the submitted search. Column order supports dragging and keyboard-accessible move buttons. CSV and Excel export only loaded rows, in the chosen column order, with that scope stated next to the controls.
