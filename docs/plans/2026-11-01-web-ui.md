# Primera experiencia web

1. Conectar una entrada específica de navegador sin modificar el inicio de Electron.
2. Implementar acceso y registro con Better Auth y sesión en cookies del servidor.
3. Conectar proyectos, documentos, credenciales, emparejamiento de runner y consultas a las API existentes; mostrar los estados reales y las limitaciones actuales.
4. Verificar el cliente compilado y el flujo contra Miniflare, incluyendo vistas estrechas. No habilitar ni desplegar runners alojados.

La interfaz conserva las convenciones de Savia y no guarda datos de negocio ni credenciales en almacenamiento del navegador. Es un primer recorrido, no paridad funcional con el cliente de escritorio.
