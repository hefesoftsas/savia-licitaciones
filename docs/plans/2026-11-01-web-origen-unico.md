# Origen único para la web local

1. Compilar una entrada web independiente, sin cargar la aplicación Electron.
2. Servir los archivos y la API con una configuración Wrangler exclusivamente local, manteniendo las rutas de API en el Worker.
3. Verificar en Miniflare archivos, navegación, autenticación Better Auth y proyectos desde un mismo origen.
4. Documentar el arranque y comprobar los builds existentes. No desplegar ni activar runners alojados.
