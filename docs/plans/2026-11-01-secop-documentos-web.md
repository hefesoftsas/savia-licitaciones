# Documentos SECOP en web

- Mostrar el índice público de documentos de un proyecto SECOP II, incluyendo aviso cuando la fuente sea parcial o truncada.
- Permitir importar documentos seleccionados individualmente a R2. El Worker vuelve a verificar el documento contra el portafolio y descarga solo desde la ruta oficial fija.
- Conservar PDF, DOCX, DOC, XLS y XLSX con límite y comprobación de firma; ZIP queda pendiente de expansión controlada. Evitar duplicados por proyecto y documento.
- Verificar con Miniflare y fuentes simuladas propiedad, pertenencia, tamaño, contenido, repetición y almacenamiento; sin tráfico externo en las pruebas.
