# Progreso de consulta Pi

Persistir una etapa acotada en las tareas de proyecto mediante la renovación de su concesión. El runner convierte eventos Pi en categorías sin texto ni rutas; la web muestra la etapa solo mientras la tarea esté activa. Mantener aislamiento, cancelación y compatibilidad con runners anteriores. Probar Miniflare, runner y compilación web, sin servicios alojados.
