# Consumo reportado en el chat web

Recoger los tokens de mensajes de Pi para las consultas de documentos, sumando solo valores válidos. Marcar las llamadas sin cifras como no reportadas y no calcular precios. Guardar el resumen junto al resultado y mostrarlo al propietario; no registrar texto ni credenciales. Probar datos completos, parciales y ausentes, el transporte simulado y la entrega de resultados sin red externa.
