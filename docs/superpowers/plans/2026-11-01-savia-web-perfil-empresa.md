# Perfil de empresa en Savia web

**Objetivo:** trasladar el perfil empresarial del escritorio a la cuenta web y usarlo como fuente para las recomendaciones de oportunidades y otros flujos existentes, sin asumir que los datos están completos.

**Diseño:** mantener en D1 los campos de `credential_library_profile` por propietario, con versión y actualizaciones atómicas para evitar sobrescrituras entre sesiones. Conservar valores de texto tal como los introduce el usuario; imágenes y otras entidades de la biblioteca requieren importaciones y almacenamiento independientes. La migración desde respaldo se hará mediante un recibo idempotente y no sustituirá el perfil existente. La interfaz en español e inglés permitirá revisar y editar el perfil completo, avisará de cambios sin guardar y distinguirá las preferencias de marca de agua del procesamiento de archivos. Las recomendaciones se implementarán después con Pi en el runner local y consentimiento explícito para los datos enviados al proveedor.

1. Probar y crear el contrato de perfil, aislamiento por cuenta, validación y concurrencia en Miniflare.
2. Agregar migración desde el respaldo empresarial, con reintentos, conflictos y datos históricos; probar con la base real de ejemplo y el paquete del runner.
3. Añadir una interfaz editable es/en, comprobar persistencia y navegación con borradores sin guardar; no desplegar.
4. Incorporar recomendaciones SECOP: fuentes revisadas, preferencias, lista y revisiones, consulta acotada, Pi local, consentimiento, programación mientras la web está abierta y descarte de fuentes obsoletas.

**Estado:** API de perfil y migración D1 creadas; Miniflare verifica aislamiento, validación y concurrencia entre sesiones. La marca de agua solo queda registrada, no se aplica a archivos. La interfaz de edición es/en está conectada, protege borradores al navegar y conserva cambios tras conflictos de versión. Pasaron la representación, las pruebas de API y las compilaciones de escritorio y web. La revisión visual interactiva sigue pendiente porque el navegador local está deshabilitado. La migración del perfil desde respaldo está implementada con un recibo atómico y no reemplaza el perfil web. Se probó con un respaldo SQLite sintético histórico y con el runner empaquetado en macOS arm64, incluidos concurrencia, fallo transaccional y reintentos tras edición. Las imágenes disponibles del perfil se transfieren con recibos y se informan las ausentes o incompatibles; la interfaz permite verlas, añadirlas y retirarlas por categoría. Faltan recomendaciones, revisión con un respaldo real y verificación de otras plataformas.
