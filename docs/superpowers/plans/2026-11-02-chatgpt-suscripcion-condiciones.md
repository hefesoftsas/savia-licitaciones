# Uso del plan ChatGPT en Savia web

La [guía oficial de Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart) describe una autorización separada para que aplicaciones participantes usen el plan del usuario mediante Responses API; iniciar sesión por sí solo no concede ese acceso. El [ejemplo oficial para proyectos de código abierto](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt) indica que los proyectos de pago o alojados remotamente deben solicitar acceso antes de ofrecer esa integración. Savia web está prevista como aplicación alojada y comercial: la existencia del proveedor `openai-codex` en Pi no demuestra que este producto esté autorizado para ofrecer el uso de una suscripción.

Mientras no se haya confirmado la elegibilidad del producto y su acceso, mantener disponible OpenAI API con clave propia y no habilitar ni prometer uso de suscripción de ChatGPT. Una futura integración autorizada necesitará consentimiento separado, gestión de sesión y revocación, selección de modelo y verificación completa del protocolo con Pi; tampoco se debe confundir con el inicio de sesión de Better Auth. No se ha solicitado acceso en nombre del usuario.
