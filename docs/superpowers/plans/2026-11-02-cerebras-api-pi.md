# Cerebras API en Pi

- Admitir credenciales cifradas de Cerebras asociadas a la cuenta y habilitar las rutas existentes del runner.
- Registrar Pi con destino fijo `https://api.cerebras.ai/v1`, Chat Completions y compatibilidad de su catálogo, sin fallback.
- Probar herramientas reales de Pi con transporte simulado, concesiones y aislamiento en Miniflare; probar la distribución independiente.
- Mostrar la opción en la web y documentar que modelo y límites se verifican por el usuario; sin solicitudes o despliegues reales.
