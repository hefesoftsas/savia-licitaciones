# Z.AI API estándar con Pi

Incorporar credenciales de Z.AI por cuenta usando el endpoint estándar `https://api.z.ai/api/paas/v4` y la compatibilidad por modelo del catálogo Pi. No utilizar el endpoint Coding Plan ni presumir que las suscripciones autorizan integrar este producto. Los modelos sugeridos no garantizan disponibilidad con la clave. Mantener los límites configurados, el consentimiento existente y destinos fijos.

Probar herramientas, credenciales y aislamiento con respuestas simuladas y Miniflare; ejecutar compilación y distribución sin inferencia externa ni despliegue.
