# Calendario mensual de agenda web

Añadir a la agenda existente una vista mensual con semanas de lunes a domingo y mes inicial calculado en la zona de Bogotá. El calendario cuenta las mismas tareas, cierres y vencimientos de la lista sin crear eventos ni recordatorios nuevos. Al seleccionar un día filtra la lista; la navegación de mes limpia el filtro y se puede volver a mostrar todas las fechas.

Reutilizar el cálculo del escritorio, probar años bisiestos, navegación entre años, recuento por día, idiomas y estados vacíos. Mantener accesibilidad de botones y avisos sobre fechas no verificadas; compilar ambas variantes y anotar la revisión visual pendiente si el navegador está deshabilitado.

**Estado:** calendario mensual conectado a los datos existentes de agenda, con recuentos, filtro por día y cambio de mes. Pasaron las pruebas de fechas, representación en ambos idiomas y recordatorios existentes; también las compilaciones web y del cliente. La revisión visual y las pruebas interactivas siguen pendientes porque el navegador local está deshabilitado.
