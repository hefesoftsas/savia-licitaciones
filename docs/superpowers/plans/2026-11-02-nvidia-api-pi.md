# NVIDIA NIM API en Pi

Añadir credenciales NVIDIA NIM a los flujos existentes, usando el endpoint fijo y los ajustes, cabeceras y razonamiento del catálogo de Pi cuando el modelo sea conocido. Probar llamadas a herramientas con transporte simulado, aislamiento de credenciales y paquete independiente; no desplegar ni usar una cuenta real.
