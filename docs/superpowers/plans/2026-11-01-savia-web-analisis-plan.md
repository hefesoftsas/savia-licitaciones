# Análisis previo al índice del plan técnico

1. Crear tareas independientes para resumir proyecto, criterios técnicos y composición del documento de respuesta, con documentos seleccionados y consentimiento explícito.
2. Ejecutarlas con Pi en el runner local y conservar los resultados como propuestas vinculadas a la versión de sus fuentes.
3. Permitir que el usuario revise y acepte cada propuesta de forma explícita; guardar las versiones aceptadas en D1, protegidas frente a cambios simultáneos y fuentes modificadas.
4. Mostrar el estado de los análisis, la procedencia y la advertencia cuando los documentos cambien. Usar estos análisis como entrada para el flujo de generación del índice en etapas posteriores.
