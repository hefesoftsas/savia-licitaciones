# Claude API nativa mediante Pi

1. Probar una sesión Pi con Messages y flujo SSE simulado, incluyendo lectura de documento, llamada de herramienta y clave de API confinada al endpoint Anthropic.
2. Registrar el protocolo nativo de Pi solo en el runner web, preservando el proxy y el comportamiento de escritorio existentes.
3. Habilitar la credencial de API por cuenta, sus controles de propiedad y la selección en los flujos probados; no usar credenciales de suscripción ni OAuth de Claude Code.
4. Ejecutar pruebas del runner, Miniflare, empaquetado y compilación sin usar la red ni claves reales.
