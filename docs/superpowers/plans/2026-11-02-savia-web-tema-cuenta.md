# Apariencia web por cuenta

Persistir el modo claro, oscuro o de sistema junto al idioma de cada cuenta en D1, sin guardar preferencias en el navegador. El modo de sistema sigue los cambios del dispositivo. Reutilizar variables de tema compartidas y adaptar los colores propios de la web; conservar el estilo claro actual. Probar aislamiento, migración y actualizaciones parciales, además de selección, contraste y compilación.
