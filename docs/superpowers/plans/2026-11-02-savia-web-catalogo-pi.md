# Catálogo Pi para credenciales web

Generar una instantánea mínima y verificable del catálogo Pi instalado para los proveedores ya integrados. Mostrar identificadores y permitir aplicar límites explícitamente sin prometer disponibilidad, herramientas o precios. Mantener entrada manual y validaciones existentes; Fireworks conserva su restricción al catálogo. Probar integridad contra la dependencia instalada, la interfaz y compilación web sin consultas externas.
