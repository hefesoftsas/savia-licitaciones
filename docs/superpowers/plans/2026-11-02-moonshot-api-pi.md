# Kimi API internacional con Pi

Soportar claves personales de Kimi API con endpoint fijo `https://api.moonshot.ai/v1` y el protocolo Chat Completions de Pi. Utilizar compatibilidad del catálogo instalado y conservar `reasoning_content` al enviar resultados de herramientas. Respetar límites configurados por cliente, sin usar Kimi Code ni asumir que sus suscripciones son intercambiables.

Verificar con respuestas simuladas el razonamiento y herramientas, y con Miniflare la credencial cifrada y concesión entre cuentas. Comprobar los servicios, catálogo y empaquetado. No realizar inferencia externa ni despliegue.
