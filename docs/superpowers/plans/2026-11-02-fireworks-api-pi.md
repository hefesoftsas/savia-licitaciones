# Fireworks API en Pi

Elegir el protocolo y endpoint fijo desde el catálogo integrado de Pi: Messages o Chat Completions según el modelo. Rechazar modelos que el catálogo no identifique para no asumir su protocolo. Conservar los límites configurados, compatibilidad y cabeceras del modelo; cubrir ambos transportes con herramientas simuladas, credenciales, flujos de cuenta y paquete independiente.
