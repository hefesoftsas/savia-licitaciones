# Comparación de evaluaciones de ofertas

El escritorio permite seleccionar de dos a cinco evaluaciones terminadas, ver criterios, fuentes, citas y revisiones humanas sin seleccionar ganador. Solo agrupa citas literales de una fuente con la misma identidad y texto completo; las citas duplicadas dentro de una evaluación permanecen separadas. La web debe mantener esas reglas y advertir cuando dos evaluaciones comparten documentos de oferta.

1. Reutilizar y probar la comparación del escritorio con fuentes cambiadas, citas idénticas ambiguas y revisiones individuales.
2. Consultar exclusivamente evaluaciones terminadas y conservadas del proyecto mediante las rutas existentes; permitir seleccionar entre dos y cinco, limpiar resultados cuando cambie la selección o el proyecto y manejar fallos sin usar datos anteriores.
3. Mostrar una tabla desplazable y accesible, fuentes, citas, notas y puntajes revisados, en español e inglés; indicar que citas coincidentes no demuestran equivalencia y no elegir un ganador.
4. Probar representación y compilaciones; documentar que la revisión visual interactiva está pendiente si el navegador sigue deshabilitado. No activar runner alojado ni consultar modelos.

**Estado:** la web permite elegir entre dos y cinco evaluaciones terminadas con informe disponible y muestra citas, fuentes y revisiones guardadas sin seleccionar ganador. La lógica importada del escritorio conserva separadas las fuentes o citas ambiguas; si cambia la selección o desaparece un informe, descarta la comparación anterior. Pasaron las pruebas de agrupación y representación en ambos idiomas, el detector de diseño y las compilaciones web y del cliente. Quedan pendientes pruebas interactivas, la revisión visual en navegador y una comprobación con datos reales del usuario.
