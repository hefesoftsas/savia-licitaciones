# MiniMax API con Pi

Habilitar MiniMax internacional usando Messages de Pi y destino fijo `https://api.minimax.io/anthropic`; respetar el catálogo Pi instalado, las credenciales propias del cliente y sus límites configurados. La selección mostrará que el usuario debe verificar las condiciones y disponibilidad de su clave y modelo. No asumir que una suscripción permite uso comercial o multiusuario. Sin fallback ni servicios Cloudflare de inferencia.

Verificar llamadas de herramientas y conservación del historial mediante transporte simulado, almacenamiento cifrado y concesión entre cuentas con Miniflare, flujos de análisis y empaquetado del runner. No hacer inferencia externa ni despliegue.
