# Asistente de oferta web

Replicar el punto de entrada guiado del escritorio con tres etapas y acceso a búsqueda SECOP y proyectos existentes. Reutilizar la navegación y sus guardas de cambios sin guardar; no duplicar ni almacenar el estado del proyecto. Verificar textos y estados sin proyecto o con proyecto seleccionado, navegación integrada y compilación web.
