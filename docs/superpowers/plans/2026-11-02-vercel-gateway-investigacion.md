# Vercel AI Gateway: análisis previo

El catálogo Pi integrado incluye Vercel AI Gateway, pero no se ha habilitado. Según la documentación de Vercel, el gateway selecciona proveedores dinámicamente y puede sustituir credenciales BYOK fallidas por credenciales del sistema. La selección de un proveedor en la interfaz no garantiza por sí sola impedir ese cambio. Antes de integrarlo hay que comprobar un control efectivo para respetar la política de no cambiar proveedor silenciosamente, la prohibición de usos nuevos de OpenRouter y los límites del cliente; no basta con mostrar el catálogo. Fuentes: https://vercel.com/docs/ai-gateway/models-and-providers/provider-options y https://vercel.com/docs/ai-gateway/authentication-and-byok/byok. No se ha realizado inferencia ni cambiado configuración externa.
